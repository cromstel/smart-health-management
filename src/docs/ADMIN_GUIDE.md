# Administrator Guide

This guide is intended for system administrators and provides instructions on how to manage and configure the Smart Health Manager application.

## User Management

### Creating a New User

1.  Navigate to the **Staff** page from the main menu.
2.  Click on the **Add New Staff** button.
3.  Fill in the required user details, including their name, email, and role.
4.  An invitation will be sent to the user's email to set up their account.

### Managing Roles and Permissions

1.  Go to the **Roles** page.
2.  Here you can create new roles or edit existing ones.
3.  For each role, you can specify detailed permissions for each module of the application.

## System Settings

### General Settings

-   Navigate to the **Settings** page to configure general application settings, such as the hospital name, address, and contact information.

### Security Settings

-   On the **Settings** page, you can also configure security-related settings, such as password policies and session timeout durations.

## Super Admin Features

Super administrators have access to additional features for managing the entire system.

### Managing Hospitals

-   The **Hospitals** page allows super admins to add, edit, and manage multiple hospital accounts within the system.

### System-Wide Audit Logs

-   Super admins can view audit logs for the entire system from the **Super Admin Audit Logs** page, providing a comprehensive overview of all activities.
