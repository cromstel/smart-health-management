# AI Skills

Project skills (opencode, `.opencode/skills/`):

| Skill | Trigger |
|---|---|
| `frontend-refactor` | Refactoring/polishing any React page or component (UI/UX, a11y, design-system compliance) |
| `backend-api` | Implementing/modifying routes, controllers, services, middleware, schema, or server tests |
| `security-review` | Auditing secrets, PHI protection, auth, injection, dependency advisories (read-only) |
| `testing` | Writing/running vitest or Playwright tests for any layer |
| `documentation` | Updating README, docs/, ai/ memory, AGENTS.md, todo checklist |
| `production-readiness` | Preparing for production: builds, env, TLS, PWA policy, backups, deployment checklist |

Load the matching skill before starting a task that matches its description. Skills carry the detailed workflow; agents/commands reference them.
