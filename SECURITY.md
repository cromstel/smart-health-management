# Security Policy

## Supported Versions

All versions of this project are currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| All     | :white_check_mark: |

## Reporting a Vulnerability

Cromstel IT Group is committed to maintaining the security and integrity of this project. We encourage responsible disclosure and appreciate the efforts of security researchers and users who help keep our systems safe.

If you discover a potential security vulnerability, please report it through our official security communication channel:

**Security Contact Page:**  
https://cromstelit.com/contact-us/

### What to Include in Your Report

To help us assess the issue as efficiently as possible, please provide:
- A detailed description of the vulnerability  
- Steps to reproduce or proof-of-concept  
- The potential impact of the issue  
- Any suggested fixes or mitigations  

### What to Expect

- **Acknowledgement:**  
  We will acknowledge receipt of your report within **72 hours**.

- **Initial Assessment:**  
  Within **5 business days**, our security team will evaluate the report and determine whether further details are required.

- **Remediation Timeline:**  
  Confirmed vulnerabilities will be addressed based on severity. You will receive updates at least **every two weeks** until resolution.

- **Coordinated Disclosure:**  
  After a fix is deployed, we will publish a security advisory summarizing the issue. Credit will be given to the reporter if desired.

### Declined Reports

If the issue is determined not to be a security vulnerability, we will provide an explanation and, if relevant, redirect you to the appropriate support or issue-tracking channels.
